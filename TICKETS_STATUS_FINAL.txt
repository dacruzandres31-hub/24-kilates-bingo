┌─ FLUJOS DE USUARIO ────────────────────────────────────────────────────────┐
│                                                                            │
│ 🎮 ESCENARIO 1: Compra con Ticket                                        │
│    Usuario tiene Tickets Bronce                                          │
│         ↓                                                                 │
│    Va a Sala Bronce (Costo: $5 normal)                                  │
│         ↓                                                                 │
│    Sistema detecta: "¿Tienes Tickets?"                                  │
│         ↓                                                                 │
│    SÍ → Usa Ticket GRATIS (quantity--)                                  │
│    NO → Usa Dinero (balance--)                                          │
│         ↓                                                                 │
│    ✅ Resultado: Cartón asignado                                        │
│                                                                            │
│ 🎮 ESCENARIO 2: Ganador de LÍNEA                                         │
│    Usuario completa LÍNEA en Sala 19:00                                 │
│         ↓                                                                 │
│    POST /api/game/end-free-game { winType: "linea" }                    │
│         ↓                                                                 │
│    Backend: SELECT skin random WHERE rarity != 'legendary'              │
│         ↓                                                                 │
│    ✅ Resultado: "¡Ganaste Marco de Fuego!"                             │
│                                                                            │
│ 🎮 ESCENARIO 3: Ganador de BINGO                                         │
│    Usuario completa BINGO en Sala 19:00                                 │
│         ↓                                                                 │
│    POST /api/game/end-free-game { winType: "bingo" }                    │
│         ↓                                                                 │
│    Backend:                                                              │
│      1. SELECT skin_legendary                                            │
│      2. SELECT ticket_bronce                                             │
│      3. INSERT/UPDATE ambos en inventory                                 │
│         ↓                                                                 │
│    ✅ Resultado: "¡BINGO! Legendaria + Ticket"                          │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
